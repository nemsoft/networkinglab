# networkinglab
A repo where we experiment and learn network code.

## Pre-reqs
- Create GitHub account, note your username or email used for the account.
- Install Git on your desktop.
- Install OpenJDK: 
    https://learn.microsoft.com/en-us/java/openjdk/install?tabs=exe%2Chomebrew%2Cubuntu
- Use VSCode with these Extensions:
    Extension Pack for Java
- You might need to run these commands to bind your Github account with VS Code:
    git config --global user.name "Your Name"
    git config --global user.email "your@email.com"
